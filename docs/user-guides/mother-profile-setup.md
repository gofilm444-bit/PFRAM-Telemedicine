# Panduan profil ibu

Setelah login mobile, lengkapi profil pribadi, pilih wilayah berantai dan fasilitas aktif, lalu isi profil kehamilan. Jika HPHT tidak diketahui, masukkan usia kehamilan berdasarkan penilaian tenaga kesehatan beserta tanggal penilaiannya. Ringkasan di Beranda bukan diagnosis dan dapat diperbarui setelah pemeriksaan.
