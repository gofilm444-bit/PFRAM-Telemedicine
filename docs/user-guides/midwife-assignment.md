# Panduan penugasan bidan

Hanya administrator yang dapat menetapkan atau mengganti bidan. Bidan harus aktif dan terhubung dengan fasilitas; override memerlukan alasan. Pergantian wajib beralasan, menutup penugasan lama sebagai `REPLACED`, dan membuat penugasan baru. Bidan hanya melihat ibu dengan penugasan `ACTIVE` miliknya.
